# results/

Hier liegen **kleine Belege** zu den Versuchen: Screenshots, Vorschau-Bilder,
kurze Beispiel-Clips (wenige MB), Workflow-JSON-Dateien.

**Große Videos gehören nicht hierher.** Sie liegen außerhalb des Repos in einer
Cloud-Ablage; pro Versuch verweist die zugehörige `analysis/`-Datei mit einem Link
darauf. Die genaue Ablage ist noch festzulegen.

Ablage-Schema: `results/NNN-kurzname/` — gleiche Nummer wie Spec/Plan/Analysis.
